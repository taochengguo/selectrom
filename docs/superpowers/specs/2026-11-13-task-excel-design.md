# 抽样任务 Excel 导入

用户已确认：抽样样品数表示抽样数量；预览允许修改和删除；只有全部信息相同才视为重复，其他采用已提出方案。

后续确认：从任务列表打开弹窗，上传、预览编辑、删除及校验在弹窗内完成；上传阶段窄窗，预览阶段宽窗，成功后刷新任务列表。支持正常页面请求作为兼容入口。

采用上传、可编辑预览、确认导入三个步骤，沿用管理平台权限、表单验证、任务创建和审计。相比直接导入，可在写入前修正问题；相比另建标准模板，直接兼容用户的20列表格。

每条非空数据行生成草稿任务，统一选择抽样组，不自动分配人员。任务编号自动生成。样品总数量可空，现场填写。品类名称新增独立字段；备注保留。原表序号、抽样人员、完成样品数、检查状态作为来源信息保存，不改变实际执行状态。

全部信息指所有可编辑业务字段（含分组、总数量、备注、品类）及原表辅助信息；不含系统生成的编号、名称、创建时间和操作者。只规范日期和整数类型，不忽略文本大小写或内部空格。上传内及与当前已有任务都比较，确认时重新比较。预览删除只移除本次待导入行。

支持 .xlsx；限5MB、500条、解压40MB。拒绝公式、未知列、重复列头、无采购订单号列、超限和损坏文件，避免静默丢失内容。有效文件的缺失采购号、非法日期和数量等错误定位到行字段，用户可修改或删除。原表辅助列也可修改。确认时所有保留行必须有效，重复行跳过，其余事务性创建，失败不部分写入。草稿通过现有待执行、随机分配流程继续。

上传草稿保存在当前用户的服务器会话中，采用独立令牌隔离多个预览。确认后清除令牌；同一分组导入通过锁定分组串行化查重及写入。原文件不持久保存。不部署、不提交用户真实表格数据。
